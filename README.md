## ✨ Features

- **Warm Cream Aesthetic**: High-contrast, elegant cream theme (`#F8F5EE`) with deep slate typography (`#0F172A`) and crisp elevated cards.
- **Interactive Hero Terminal**: Animated terminal typing simulation showcasing developer commands and live status.
- **Featured Project IDE Mockup**: VS Code / Electron desktop environment preview with live collaboration indicator and review comments.
- **Filterable Projects Grid**: Dynamically filter projects by category (`ALL`, `WEB`, `DESKTOP`, `BACKEND`, `AI`, `SYSTEMS`).
- **Interactive Journey Timeline**: Chronological learning roadmap tied directly to real-world projects.
- **Grouped Technical Stack**: Structured breakdown across Languages, Frontend, Backend, Database, Desktop, Tools, and AI.
- **GitHub Corner**: Interactive contribution graph and language breakdown.
- **Active Navigation Indicator**: Floating sticky navbar with smooth section tracking and mobile responsive drawer.
- **SEO & Accessibility**: Fully accessible with semantic HTML5, JSON-LD structured data, Open Graph tags, and reduced-motion support.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/omkarsai24/omkar-portfolio.git

# Enter project directory
cd omkar-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
