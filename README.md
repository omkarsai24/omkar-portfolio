# Omkar Sai — Developer Portfolio

Personal portfolio of **Omkar Sai Ravinuthala** — Software Developer.

Built with React + TypeScript + Vite + Tailwind CSS + Framer Motion.

## Features

- Interactive animated hero terminal
- IDE-style featured project mockup (Developer Collaboration Platform)
- Filterable project grid (Web / Desktop / Backend / AI / Systems)
- Animated journey timeline and grouped skills showcase
- GitHub section with original contribution-activity visual (placeholder stats)
- Sticky nav with active-section indicator + animated mobile drawer
- Fully responsive, keyboard accessible, `prefers-reduced-motion` aware
- SEO metadata, Open Graph tags, JSON-LD, custom SVG favicon
- All content driven by `src/data/portfolio.ts` — no UI edits needed

## Tech stack

React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion · Lucide React · ESLint · Prettier

## Getting started

```bash
npm install
npm run dev        # local dev server
npm run build      # type-check + production build → dist/
npm run preview    # preview the production build
npm run lint       # eslint
```
